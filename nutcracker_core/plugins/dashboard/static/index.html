          Avanzado: relay (frida/adb remoto) / adb kill-server
          

            El relay puentea `frida`/`adb` corriendo en este backend hacia el device
            conectado acá. `adb` (shell/install/pull/screencap) reusa la conexión USB
            (requiere el video USB activo). `frida` va por un WebSocket nativo directo
            a la IP de LAN del device (Tango no sostiene bien el handshake WebSocket
            que usa frida moderno, verificado en vivo) — necesita que ESTA PC tenga
            alcance de red al device, y puede pedir el permiso "Acceso a Red Local" de
            Chrome la primera vez. `adb kill-server` mata el daemon adb (WSL + Windows)
            para soltar el cable antes de que WebUSB lo reclame.
